# 🚀 CodeJourney – Personal Progress Tracker

CodeJourney is a Python project that helps users keep track of their coding journey. 
It allows users to create a profile, record their daily coding progress, and view their learning statistics.

## Features

- Create and view user profile
- Add coding practice details
- Store progress using JSON files
- View previous coding sessions
- Search progress based on date
- Dashboard to check:
  - Number of study sessions
  - Problems solved
  - Total hours spent coding
- Handles invalid user inputs

## Technologies Used

- Python
- JSON

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run:

```bash
python CodeJourney.py
